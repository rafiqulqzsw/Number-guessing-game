# Number-guessing-game
A simple number guessing game - Python

**What it is?**
The program randomly chooses a number, and the player has to guess what it is. after each guess, the program tells the player if it is too high or too low.

**Why i made it?**
This is one of my first python projects to practise fundamentals of python and get more comfortable writing programs from scratch.

**What i learned**
-variables and data types
-if / elif / else statements
-while loops
-User input
-random number generation
-basic error handling
-basic fundamentals
